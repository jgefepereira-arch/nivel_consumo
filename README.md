# 🚰​ **Classificação de consumo de água**

Este projeto foi desenvolvido para **classificar por cores** o nível de consumo de água por cada indíviduo, **baseando-se na função programada**, a qual funciona considerando os índices de cada item da lista mencionada abaixo:

## 🎨​ Possíveis classificações

- **Vermelho**: Muito baixo (crítico).
- **Amarelo**: Baixo.
- **Verde**: Médio.
- **Ciano**: Alto.
- **Azul**: Muito alto (alerta).

Estas classificações foram formatadas com a **Biblioteca externa COLORAMA**
